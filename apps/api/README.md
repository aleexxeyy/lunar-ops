# Lunar Ops — API

Сервер NestJS керує ігровими сесіями, перевіряє команди через спільні схеми Zod і викликає симуляцію з `packages/game-core`. Остаточний стан місії зберігається в пам’яті сервера; перезапуск видаляє сесії.

## Розробка

Виконайте `pnpm install` і `pnpm dev` у корені репозиторію, щоб запустити всі пакети разом. API використовує порт 3000 за замовчуванням; змінна `PORT` дозволяє змінити порт.

Для окремого запуску API після збирання спільних пакетів:

```sh
pnpm --filter @lunar-ops/api dev
```

## Перевірки

Команди виконуються з кореня репозиторію:

```sh
pnpm build
pnpm --filter @lunar-ops/api typecheck
pnpm --filter @lunar-ops/api test
pnpm --filter @lunar-ops/api test:e2e
```

Повідомлення про помилки, записи журналу та ігрові сценарії надходять до інтерфейсу українською. Ідентифікатори та структура API визначені в `packages/contracts`.

Правила гри, архітектура та повний порядок перевірок описані в [головному README](../../README.md).
