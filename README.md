# Lunar Ops

Учебный тренажёр лунной миссии для Junior Astronaut Mission Trainer / NASA Space Apps Challenge 2026. Интерфейс командного терминала: адаптивная схема станции, ресурсы, операции, экипаж, события и журнал.

## Запуск

Нужны Node.js 24 и pnpm 11.25.0.

```sh
pnpm install
pnpm dev
```

Откройте адрес Vite (обычно http://localhost:5173). API запускается на порту 3000; Vite проксирует `/api`. Для production нужен такой же reverse proxy. Фронтенд работает с настоящим API: при отсутствии связи показывает ошибку и кнопку повторного подключения.

## Миссия

Сохраните экипаж в течение 7 игровых дней и получите 60 научных данных. На день доступны две операции; каждую обычную операцию можно выполнить один раз. Улучшение модуля также занимает операцию. Роли экипажа меняются бесплатно, а бонусы действуют при завершении дня. События требуют решения перед продолжением. Есть уровни «Кадет» и «Командир».

Дни, проценты ресурсов и события — условная учебная модель, без оперативных данных NASA. Баланс и сценарии находятся в `packages/game-config`.

## Архитектура

- `apps/web`: React, Zustand, Tailwind, Recharts, Framer Motion; только отображение и отправка команд.
- `apps/api`: NestJS, проверка команд Zod, хранение авторитетного состояния сессий в памяти.
- `packages/contracts`: общие типы, схемы входящих запросов.
- `packages/game-core`: детерминированная симуляция, доступность действий, расходы, производство, события, победа и эвакуация.
- `packages/game-config`: баланс, роли, модули, сценарии.

В браузере сохраняется только идентификатор сессии. Обновление страницы восстанавливает состояние через API. Перезапуск API сбрасывает сессии; интерфейс сообщает об этом и создаёт новую. Базы данных и авторизации нет. Проверка `revision` предотвращает повторное применение устаревших команд из других вкладок.

## Проверки

```sh
pnpm build
pnpm typecheck
pnpm test
pnpm --filter @lunar-ops/api test:e2e
pnpm --filter @lunar-ops/web test:e2e
```

Playwright использует установленный Google Chrome; для Edge задайте `PLAYWRIGHT_CHANNEL=msedge`. Браузерные тесты сами запускают собранный API и Vite, если порты свободны. Перед ними выполните `pnpm build`. Проверяются desktop/mobile, навигация, диалоги, улучшения, роли, экспорт, восстановление связи, новая миссия и полный проход до победы.
